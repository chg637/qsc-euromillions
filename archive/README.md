# Archive

Versions v36 à v39 du protocole QSC EuroMillions, avec leurs tests, prompts de tâche et rapports d'application. Rangées ici le 21/11/2026 pour alléger la racine.

Figées, non maintenues, hors CI. Les tests archivés ne sont pas garantis : `test_qsc_v39.py` importe `popularite`, qui vit à la racine du dépôt. Pour les rejouer, copier le fichier voulu à la racine.

La version en production est `qsc_euromillions.py` (racine), et le Loto est dans `loto/`.
